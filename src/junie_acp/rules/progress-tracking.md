# Progress Tracking — ACP

Use `update_status` to report progress at the timing points defined in the shared progress-tracking rule.

## ADVANCED_CHAT Complex Research [OVERRIDE]

When in `[ADVANCED_CHAT]` and the task is a complex research or multi-angle investigation, override the default no-update restriction: call `update_status` before each major research step (each search, each source read, each synthesis phase) so the user can follow progress in real time.
